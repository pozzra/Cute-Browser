# 🌟 Cute Browser

**Cute Browser** is a high-performance, aesthetically-driven mobile web browser built with Flutter. It blends a "Premium Glass-Cute" design language with powerful productivity features, creating a browsing experience that is both professional and visually delightful.

---

## ✨ Key Features

### 💎 Premium Glass-Cute UI
- **Glassmorphism Aesthetic**: A modern interface featuring high-end translucency, background blurs, and subtle reflections.
- **Adaptive Theme**: Seamlessly transitions between a crisp Light mode and a deep, tonal Dark mode.
- **Fluid Animations**: Organic, bouncy entrance animations and tactile haptic feedback for a premium feel.

### 📺 YouTube Premium Emulation
- **Ad-Skipper**: Intelligent, automated ad-skipping logic that identifies and clicks skip buttons across various YouTube layouts.
- **Background Play**: Advanced visibility mocking and silent audio loops allow videos to keep playing even when the app is minimized.
- **Picture-in-Picture (PiP)**: Native PiP support allowing users to multitask while keeping their video content visible in a floating window.

### 🛠️ Productivity & Privacy
- **Smart Ad-Blocker**: Integrated script injection to remove intrusive banners and trackers from most websites.
- **Tab Management**: Efficient multi-tab system with a visual grid overview for quick switching.
- **Safe Browsing**: Real-time security checks to warn users about non-HTTPS websites.
- **Customizable Dashboard**: A personalizable home screen with "Quick Magic" links and dynamic greetings.

## 🚀 Technical Stack

- **Framework**: [Flutter](https://flutter.dev)
- **State Management**: [Provider](https://pub.dev/packages/provider)
- **WebView Engine**: `webview_flutter`
- **Typography**: [Google Fonts (Nunito)](https://fonts.google.com/specimen/Nunito)
- **Platform Support**: Android & iOS

## 🛠️ Getting Started

### Prerequisites
- Flutter SDK (Latest Stable)
- Android Studio / Xcode

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/kun-amra/cute_browser.git
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
